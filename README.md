# Siriluk W. - Portfolio

A professional, modern, dark-themed portfolio website designed for a Senior UI Developer. Built with a focus on clean typography and responsive design.

## Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Dark/Light Theme Toggle:** Easily switch between dark (default) and light modes.
- **Developer-Focused Typography:** Uses JetBrains Mono for a clean, code-centric aesthetic.
- **Showcase Grid:** Responsive layout for project visualization.

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theme management)
- Vanilla JavaScript (for theme toggling)
- Google Fonts (JetBrains Mono)

## Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.
